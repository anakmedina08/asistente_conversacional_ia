# asistente_conversacional_ia

Asistente conversacional basado en Inteligencia Artificial para la consulta y análisis de datos operativos en el sector asegurador.

El proyecto integra pipelines ETL, prácticas de DataOps y modelos de analítica avanzada para permitir consultas en lenguaje natural sobre información operativa, facilitando la toma de decisiones y el acceso a datos dentro de entornos empresariales.

## Objetivo
Desarrollar un asistente conversacional capaz de interpretar preguntas en lenguaje natural y generar respuestas basadas en datos operativos integrados desde diferentes fuentes.

## Tecnologías involucradas
- Inteligencia Artificial
- NLP (Natural Language Processing)
- Pipelines ETL
- DataOps / AIOps
- Modelos predictivos
- APIs de consulta de datos

## Contexto
Este proyecto hace parte de un trabajo de grado enfocado en la aplicación de IA para mejorar el acceso y análisis de datos operativos en el sector asegurador.
